Linux System Information and Monitoring Script

Project Overview

This project demonstrates practical Linux system administration and Bash scripting skills using Ubuntu Linux on Windows Subsystem for Linux (WSL 2).

The script collects essential system information and generates a report containing details about the current user, hostname, date and time, disk usage and memory usage.

Technologies Used

Ubuntu Linux
Bash scripting
Windows Subsystem for Linux (WSL 2)
Linux command-line utilities

Project Objectives

Practise Linux command-line administration
Automate system information collection using Bash
Monitor disk and memory utilisation
Generate a reusable system information report
Develop practical Linux skills relevant to DevOps engineering
